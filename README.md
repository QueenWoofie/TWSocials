# TWSocials

This project is a responsive front-end for a basic social media application. It's built using **Tailwind CSS** as part of the Noroff CSS Frameworks assignment. The site includes a login page, feed, and a profile page.

## Features

- Responsive, clean layout with Tailwind CSS
- Authentication form with HTML validation
- Feed page with search bar, dropdown filter menu
- Profile page with user posts, profile image, and follower dispaly

## Prerequisites

- Node.js
- npm

## Getting Started

1. Clone Repository

```bash
git clone https://github.com/QueenWoofie/TWSocials.git TWSocials
cd TWSocials
git checkout css-frameworks
```

2. Install dependencies

```bash
npm install
```

3. Run Tailwind

```bash
npm run dev
```

4. Build production-ready CSS file

```bash
npm run build
```

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
